# Sanitized SQL — Group 10

This package contains 20 SQL files prepared for public-code staging after a privacy/PII review.

Direct student identifiers were removed from public output where practical. Schema fields used internally for joins, matching, and calculations remain when required by query logic. Two literal Banner IDs found in a developer comment were removed. Do not commit query results, exports, screenshots, or other files containing student records.

The complete sanitized SQL set is in `financial-aid-sql-sanitized-group-10.zip`. This review is not a legal determination of FERPA compliance.
