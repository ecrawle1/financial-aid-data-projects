# Sanitized SQL — Group 11

This package contains 6 SQL files prepared for public-code staging after a privacy/PII review.

Direct student identifiers and contact information were removed from public output where practical. Schema fields used internally for joins and calculations remain when required by query logic. Do not commit query results or other student-level data.

See `FERPA_AUDIT_GROUP_11.md` for the file-by-file review. This review is not a legal determination of FERPA compliance.
