# banner-financial-aid-holds-enrollment

Sanitized Oracle SQL examples related to financial-aid holds, advising requirements, enrollment, reenrollment, and related student-service workflows.

## Privacy

These are **sanitized public examples**, not production extracts. Direct student identifiers and hard-coded student-specific values were removed from public report output. Schema references used for joins or comparison logic may remain where necessary to demonstrate the SQL.

Do not commit query results, spreadsheets, exported student records, credentials, connection strings, or local database configuration.
