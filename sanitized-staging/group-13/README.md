# Sanitized SQL — Group 13

This package contains 15 SQL files prepared for public-code staging after a privacy/PII review.

Direct student identifiers and sensitive free-text/staff identifiers were removed from public output where practical. Schema fields used internally for joins, filtering, calculations, and comparisons remain when required by query logic. Do not commit query results, exports, screenshots, or other student-level data.

See `FERPA_AUDIT_GROUP_13.md` for the file-by-file review. This review is not a legal determination of FERPA compliance.
