# Sanitized SQL — Group 08

This package contains 20 SQL files prepared for public-code staging after a privacy/PII review.

Direct student identifiers were removed from public output where practical. Schema fields used internally for joins and calculations remain when required by query logic. Do not commit query results, exports, screenshots, or other files containing student records.

See `FERPA_AUDIT_GROUP_08.md` for the file-by-file review. This review is not a legal determination of FERPA compliance.
